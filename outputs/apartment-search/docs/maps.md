# 아파트 상세 지도

상세 페이지는 항상 공공데이터 주소와 카카오맵 검색 링크를 제공합니다. JavaScript 키가 없으면 임베디드 지도 버튼은 숨겨집니다. 키를 설정하면 사용자가 지도 보기를 눌렀을 때만 SDK와 주소 검색을 호출합니다. DB 구조나 수집 데이터는 변경하지 않습니다.

## 활성화

1. [Kakao Maps 공식 안내](https://apis.map.kakao.com/web/guide/)에 따라 앱의 지도 사용 설정과 JavaScript 키를 준비합니다.
2. 해당 JavaScript 키에 실제 접속하는 SDK 도메인을 등록합니다. 예: `http://localhost:8082`, `http://localhost:18084`, `http://127.0.0.1:18084`, `https://3-107-167-57.sslip.io`. localhost와 127.0.0.1은 별도로 등록합니다.
3. IntelliJ 실행 환경변수 또는 로컬 `.env.docker` / 서버 `.env.production`에 `KAKAO_MAP_JAVASCRIPT_KEY`를 설정합니다. REST API 키나 Client Secret을 넣지 않습니다. 환경 파일은 Git에 올리지 않습니다.
4. 앱을 다시 실행하거나 Compose 앱을 재생성합니다. Docker 소스 변경은 이미지 재빌드가 필요합니다.
5. 상세 페이지에서 지도 보기를 누르고 실제 주소 위치와 브라우저 콘솔의 도메인/CSP 오류 여부를 확인합니다.

JavaScript 키는 브라우저에 전달되는 공개 식별자입니다. 허용 도메인을 제한하고 사용량을 관리합니다. 사용자 위치 권한은 요청하지 않습니다. 지도 클릭 이후 주소가 카카오로 전달됩니다.

## 실패 처리와 범위

주소 EXACT 검색 결과가 정확히 하나이며 좌표가 유효할 때만 마커를 표시합니다. 결과 없음·복수 결과·SDK 실패·15초 응답 시간 초과에는 검색 링크를 유지하고 임의 좌표를 표시하지 않습니다. 카카오 SDK의 타일 다운로드 성공까지 자동 검증하지는 않습니다. 주소 검색 위치가 실제 출입구와 다를 수 있습니다.

CSP 외부 허용은 키가 설정된 숫자 ID 상세 경로에만 적용합니다. 다른 페이지는 기존 정책을 유지합니다. API 쿼터를 쓰는 실제 검증이나 부하 테스트는 수행하지 않았습니다.

## 검증

키 없음/있음 상세 렌더링 및 CSP 2개 MVC 테스트와 지연 로드·결과 검증·SDK 실패 3개 Node 테스트를 추가했습니다.

```sh
node scripts/test-detail-map.cjs
sh ./mvnw -Ppostgres-it verify
```

실제 키가 아직 없어 실제 지도 렌더링과 운영 도메인 허용은 활성화 시 확인해야 합니다. 현재 변경에는 배포가 포함되지 않습니다.
