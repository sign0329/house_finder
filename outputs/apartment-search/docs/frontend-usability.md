# 공개 화면 사용성 보완

## 범위

- 검색은 비로그인 상태에서 제공함. 관심 저장에는 기존 계정 인증을 유지함.
- 가격·기간 역전, 비밀번호 확인 불일치와 72바이트 초과를 제출 전에 안내함. 서버 검증도 그대로 유지함.
- 제출 중 안내와 중복 클릭 방지를 추가함. 뒤로 돌아오면 버튼 상태를 복원함.
- 본문 건너뛰기, 검색 입력 포커스 표시, 모바일 메뉴 줄바꿈과 44px 관심 버튼을 적용함.
- 빈 검색 결과에 수집 범위의 한계를 안내함. 지도 키가 없으면 외부 카카오맵 링크를 안내함.
- 기존 회원가입·로그인·관심 저장·월별 그래프를 재사용함. 외부 지도 SDK의 실제 동작은 유효한 JavaScript 키와 등록 도메인이 필요함.

## 검증

프로젝트 폴더에서 `node --test src/test/js/forms.test.cjs` 실행함. 의존성 설치 없이 Node 내장 테스트로 다음 3개 케이스를 검증함.

1. 가격·기간 역전 차단 및 값 수정 후 제출 가능함.
2. 비밀번호 확인 불일치·UTF-8 바이트 초과 차단함.
3. 제출 중 안내·재제출 차단·뒤로가기 상태 복원함.

DOM 대역을 사용하는 로직 테스트이므로 실제 브라우저 레이아웃 검증을 대체하지 않음. CI에 동일 명령을 추가함. 서버 검증은 기존 Maven verify/PostgreSQL 통합 테스트를 유지함.

## 제한

현재 데이터 출처 안내의 단일 수집 상태 정보는 전국 전체 수집 완료를 의미하지 않음. 지도 키 발급·도메인 등록, 시연 영상 제작 및 운영 배포는 별도 작업임.
