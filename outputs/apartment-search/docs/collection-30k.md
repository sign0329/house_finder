2026-10-30 로컬 PostgreSQL 기준 실제 국토교통부 거래 **31,891건**을 확보했다. 월별 스냅샷을 온전히 유지하기 위해 정확히 30,000건으로 자르지 않았다.

## 수집 및 검증

기존 importer의 `molit.regions`, `molit.from=202601`, `molit.to=202609` 옵션으로 지역을 순차 수집했다. 인증키는 기존 로컬 환경 파일만 사용했다. 기존 해제 거래 제외 및 지역·월 스냅샷 저장 로직을 사용했다.

- DB 총건수 31,891, 고유 source_key 31,891, MOLIT 외 데이터 0건 확인.
- 로컬 `http://localhost:8082/api/trades`의 total 31,891 확인.
- pg_dump 사용자 정의 형식으로 로컬 백업 생성, pg_restore --list로 아카이브 읽기 확인. 실제 복원 시험은 수행하지 않았다.

코드 변경은 없으며 추가 단위 테스트는 실행하지 않았다. 덤프와 인증키는 Git에 포함하지 않는다.

## AWS 반영 여부

사용자의 서버 중지 요청에 따라 AWS 서비스를 재시작하거나 데이터를 전송하지 않았다. 위 건수는 로컬 DB에만 적용된다. AWS의 마지막 확인 데이터는 726건이며, 재배포 시 별도 데이터 동기화가 필요하다.
