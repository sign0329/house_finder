# 아파트 월별 거래 추이

거래 상세 화면에서 같은 지역·구·아파트명·주소·정확한 전용면적의 저장된 거래를 월별로 집계한다. 공개 기능이며 로그인 없이 볼 수 있다.

- 기간: 6개월 / 1년(기본) / 3년. `/trades/{id}?months=6|12|36`.
- 기준월: 선택한 거래와 동일한 단지·면적의 DB 내 최신 계약월. 과거 거래 상세로 들어와도 최신 흐름을 보여준다.
- 월별 평균·최저·최고 거래금액과 거래량. 평균은 집계 시 소수 둘째 자리, 표시 시 만원 단위 반올림.
- 거래 없는 달: 거래량 0, 평균·최저·최고 가격은 값 없음. 가격을 0원으로 해석하지 않는다.
- 그래프: 과거→최근 순서. 위는 평균 가격, 아래는 거래량이며 각각 별도 0 기준 척도를 사용한다. 모바일에서 가로 스크롤할 수 있다.
- 상세 표는 그래프와 같은 수치를 제공한다. 기존 최근 12건 개별 거래 표는 유지한다.

## 한계

집계는 DB에 수집된 행 기준이다. 수집 누락과 실제 거래 없음은 구별할 수 없다. 최신 거래월은 오늘 날짜와 다를 수 있다. 층·계약 조건의 차이가 있으므로 평균을 시세·감정가·예측 가격으로 제시하지 않는다. 취소·정정 반영 상태는 수집 DB의 상태를 따른다.

## 구현 및 검증

`trade.TradeTrends`가 바인딩 SQL의 월별 집계를 수행한다. 원본 전체 행을 Java로 가져오지 않으며 반환하는 월은 최대 36개다. 기존 apartment/date 인덱스를 활용할 수 있고 새 스키마나 외부 차트 의존성을 추가하지 않는다.

새 테스트는 5개: 상세 모델 및 렌더링, 정확한 단지·면적별 집계, 빈 달·기간 경계 및 최신월 기준, 기간 오류·없는 거래, PostgreSQL의 월 집계 호환성. 상세 모델 누락으로 먼저 실패하는 테스트를 관찰한 후 구현했다. 테스트 fixture는 테스트 환경에만 사용하며 운영 데이터로 제공하지 않는다.

검증 결과: 기본 테스트 84개와 PostgreSQL 통합 테스트 17개 통과. 격리된 H2 fixture 서버에서 1년→6개월 선택·적용 및 좁은 화면의 가로 스크롤, 최신월 가격·거래량 막대 표시를 확인했다. 이 미리보기의 거래는 테스트 데이터이며 운영에 적재하지 않았다. 최초 전체 테스트의 고정 ID fixture 충돌은 새 테스트의 메모리 DB를 분리하여 해결했다. AWS 및 기존 8082 서버에는 아직 배포하지 않았다.
