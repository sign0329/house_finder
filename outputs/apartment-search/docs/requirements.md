# 웹 MVP 범위

## 구현된 범위 (2026-10-26)
- 지역, 아파트/구 이름, 계약 기간, 만원 단위 가격, 면적 검색.
- 날짜/가격 경계는 포함. 면적: 60 미만, 60~85 포함, 85 초과.
- 최근순/가격순 정렬 및 12건 페이지네이션. 검색 조건 유지.
- 같은 주소·단지·면적의 최근 최대 12건을 상세에서 표시.
- 관심 단지는 localStorage에 저장. 계정 동기화는 제공하지 않음.
- 데모는 고정 시드의 가상 거래 240건. 실제 공공데이터와 혼합하지 않음.
- 잘못된 입력은 400, 없는 거래는 404, 빈 결과는 안내 문구 표시.

## 다음 단계
- 누락 필드 정책과 전국 지역 코드 목록 자동 동기화.
- Spring Batch 수집 및 자동 체크포인트 재시작.
- 대량 적재, EXPLAIN ANALYZE, 키셋 페이지네이션, Redis 캐시 비교.
- 회원 인증, 실제 배포 및 부하 실험.

## 검증 상태

구현 여부와 테스트 범위는 다르다. 현재 자동 테스트 47개의 범위와 미검증 사항은 [검증 기록](verification.md)을 따른다. 종로구 202609의 실제 연결·저장·검색은 확인했다. PostgreSQL 실행·통합 테스트는 확인했고, 대용량 처리는 미검증이다.

## 공공 API 연결 코드

명시한 지역 목록·계약월 범위의 XML 수집, 전체 페이지 검증, 월별 스냅샷 갱신, 재수집 중복 방지 및 해제 반영, 별도 파일 DB와 출처 표시를 구현했다. 실제 키로 호출하기 위한 절차와 제약은 [연결 안내](public-api.md)를 따른다.
