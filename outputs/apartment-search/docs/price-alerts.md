# 관심 아파트 목표 가격 알림

마이페이지 → 목표 가격 알림(`/account/alerts`)에서 단지별 가격을 만원 단위로 설정함. 회원 본인의 관심 단지만 설정할 수 있으며 알림 해제·읽음 처리를 지원함. 받은 알림은 최신순 20건씩 조회함.

## 동작

- 매물 알림이 아닌 국토부 신고 실거래 알림임. 단지의 모든 면적·층이 대상임.
- 설정 또는 가격 변경 시점의 거래 최대 ID를 기준으로 기존 거래를 제외함. 이후 새로 수집한 거래만 평가하며 지연 신고된 과거 계약도 포함함.
- `MolitStore.replace`의 성공 스냅샷 저장 트랜잭션 안에서 알림을 함께 저장함. 수집 실패 시 거래와 알림 모두 롤백됨.
- 설정·해제와 수집이 동일한 `molit_import_state` 잠금을 사용해 수집 중 설정 경계가 섞이지 않게 함.
- `(bookmark_id, source_key)` 유일 제약으로 같은 거래의 반복 수집·재등장 알림을 방지함. 신고 내용이 정정되어 source_key가 바뀌면 별도 거래로 알릴 수 있음.
- 거래 삭제 이후에도 알림 당시 가격·면적·층·계약일은 남음. 해당 거래가 없으면 상세 링크 대신 해제·정정 가능성을 표시함.
- 관심 아파트 삭제 시 해당 단지의 알림 이력도 삭제함. 알림 해제만 하면 기존 이력은 유지됨.

## 범위 및 확인

이메일·카카오 발송과 자동 수집 예약은 포함하지 않음. 같은 DB를 사용하는 수집기가 실제 실행되어야 알림이 생성됨. SQL로 직접 복사한 거래에는 알림이 생성되지 않음. AWS·8082 배포는 별도임.

V15가 기존 관심 테이블에 목표 가격·기준 ID를 추가하고 `price_notification`을 생성함. 사용자 인증·CSRF는 기존 `/account/**` 보안 규칙을 사용함.

검증: `PriceAlertsTest`에서 설정, 신규 거래 및 중복 방지, 권한/CSRF/가격 검증, 실패 롤백, 해제/삭제를 확인함. `PostgresIT`에서 PostgreSQL 17 마이그레이션·수집 연동·중복 방지·읽음 처리를 확인함.
