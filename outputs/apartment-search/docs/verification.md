## 인증키 인코딩 수정 — 2026-10-26

신규 3개 테스트 실패를 먼저 확인한 후 Encoding/Decoding 키 호환 처리를 구현했다. `./mvnw -o -q verify` 결과 총 30개 통과(실패·오류·스킵 0). 소문자 퍼센트 이스케이프, 원래 키의 + 보존, 잘못된 인코딩의 비노출 거부를 검증했다. 이번 수정 후 실제 인증키로 외부 호출은 재실행하지 않았다.


## API 연결 코드 검증 — 2026-10-26

- `./mvnw -o -q verify`: 기존 13개 + MolitTest 14개 = **27개 통과**, 실패·오류·스킵 0개.
- 합성 XML/모의 HTTP로 값 변환·XXE 차단·페이지 누락·재시도·키 비노출·중복·취소·빈 스냅샷·롤백·검색 화면 연결 확인.
- 실제 패키징 JAR의 molit 프로필을 임시 파일 DB와 8081 포트에서 실행: health UP, 빈 실제 데이터 안내, 검색 0건, 관심 저장 구분 확인. 확인 후 테스트 서버 종료.
- Node 실행으로 가상/실제 데이터의 localStorage 키 분리 확인 및 JS 구문 검사 통과.
- 실제 인증키는 사용하지 않았으며 실제 국토부 API 호출 성공 여부는 아직 미검증.
- [실행 방법 및 수집 한계](public-api.md).

## 과거 기록 — 2026-10-13

당시 Java 22.0.2에서 Java 21 타깃 빌드와 웹 테스트 8개가 통과했습니다. 브라우저에서 한강 검색, 관심 저장·유지, 상세 이동과 차트 및 반응형 레이아웃을 확인했습니다. 현재 버전의 전체 브라우저 회귀 테스트 결과로 해석하지 않습니다.

초기 구현에서는 최초 Red 실행을 관측하지 못했으므로 전체 구현을 Red–Green TDD로 주장하지 않습니다.
