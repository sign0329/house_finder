# 회원 게시판

상단 메뉴의 회원 게시판에서 접근함. 가입 후 로그인한 USER만 목록·상세·작성 화면을 사용할 수 있음. 비로그인 접근은 로그인 페이지로 이동하며 로그인 성공 후 홈으로 이동함. 관리자 전용 계정은 회원 권한을 대신하지 않음.

- 최신 글부터 20개씩 조회함. 제목 120자, 내용 10,000자로 제한함.
- 작성자 식별은 요청 값이 아닌 세션 사용자로 처리함. 수정·삭제 SQL에서도 작성자 조건을 검사함.
- 제목·본문은 Thymeleaf 텍스트 출력으로 HTML을 이스케이프함. 모든 변경 요청에 CSRF를 적용함.
- V11 board_post에 회원 외래 키와 제목·본문·작성/수정 시각을 저장함. 글 삭제는 영구 삭제이며 화면에서 삭제 확인 단계를 제공함.
- 파일 첨부는 이번 범위에 포함하지 않음.

검증은 BoardTest의 회원 접근, 작성/출력, 작성자 권한, 입력/CSRF 검증과 PostgreSQL 통합 테스트로 구성함.

## 댓글

상단 메뉴 명칭은 게시판으로 변경함. 로그인한 회원은 글 상세에서 최대 500자 댓글을 작성하며 본인 댓글만 삭제할 수 있음. 최신순 20개씩 조회함. V12 board_comment는 게시글 삭제 시 함께 삭제됨. 세션 작성자 확인, CSRF 및 HTML 이스케이프를 적용함. 댓글 수정·답글은 제공하지 않음.

댓글 글자 수는 유니코드 코드 포인트 기준으로 계산함. 공백도 포함하며 500자 초과 시 입력란·카운터를 빨간색으로 표시하고 등록을 차단함. 기존 댓글 보존을 위해 V12 컬럼 크기는 유지하며 서버 입력 검증에 500자 제한을 적용함.

## 신고 및 관리자 조치

회원은 글·댓글에서 사유(1~500자)를 입력해 신고함. 같은 회원의 같은 대상 신고는 1건만 보존함. 신고는 자동 숨김을 유발하지 않음.

관리 기능 활성화 및 관리자 로그인 후 `/admin/board`에서 최근 신고를 20개씩 조회하고 상태 필터를 사용할 수 있음. 신고 당시 스냅샷과 현재 원문, 대상 현재 상태를 구분하여 표시함. 숨김·복원·기각은 처리 사유가 필수이며 관리자 이름과 시각을 기록함. 기각은 숨김을 해제하지 않음. 여러 신고가 같은 대상을 가리켜도 대상 현재 상태를 별도로 표시함.

숨긴 게시글은 회원 목록·상세·수정·새 댓글 등록에서 제외함. 숨긴 댓글은 목록에서 제외함. 숨김은 데이터 삭제가 아니며 복원 가능함. 대상이 삭제되어도 신고와 처리 이력은 보존하며 이후에는 기각만 가능함. 신고자는 처리 이력이나 다른 회원의 신고를 볼 수 없음.

V13은 hidden 컬럼, board_report 및 board_moderation_event를 추가함. 신고자 행 잠금과 유일 제약으로 중복 신고를 방지함. 관리자 조치와 이력 기록은 하나의 트랜잭션으로 처리함. 모든 변경은 CSRF가 필요하고 관리자 경로는 ADMIN 역할로 제한함. 관리 기능이 꺼져 있으면 관리 컨트롤러를 생성하지 않음.

신고 원문과 이력의 보관 기한·자동 삭제, 이메일 알림, 이의 제기 절차는 구현하지 않음.
