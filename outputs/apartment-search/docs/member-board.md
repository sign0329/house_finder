# 회원 게시판

상단 메뉴의 회원 게시판에서 접근함. 가입 후 로그인한 USER만 목록·상세·작성 화면을 사용할 수 있음. 비로그인 접근은 로그인 페이지로 이동하며 로그인 성공 후 홈으로 이동함. 관리자 전용 계정은 회원 권한을 대신하지 않음.

- 최신 글부터 20개씩 조회함. 제목 120자, 내용 10,000자로 제한함.
- 작성자 식별은 요청 값이 아닌 세션 사용자로 처리함. 수정·삭제 SQL에서도 작성자 조건을 검사함.
- 제목·본문은 Thymeleaf 텍스트 출력으로 HTML을 이스케이프함. 모든 변경 요청에 CSRF를 적용함.
- V11 board_post에 회원 외래 키와 제목·본문·작성/수정 시각을 저장함. 글 삭제는 영구 삭제이며 화면에서 삭제 확인 단계를 제공함.
- 댓글·파일 첨부·신고·관리자 중재는 이번 범위에 포함하지 않음.

검증은 BoardTest의 회원 접근, 작성/출력, 작성자 권한, 입력/CSRF 검증과 PostgreSQL 통합 테스트로 구성함.
